# tool-map: 입력창 위 한글 띠

Claude Code 입력창 바로 위에 지금 상태를 한눈에 보여 주는 띠를 그리는 모드입니다.

- 데스크톱 앱에서는 그림 한 장으로 그립니다.
  - 치즈 고양이와 말풍선 한마디(「넉넉해요」 「일하는 중이에요…」 「다 했어요!」)
  - 동그라미 게이지 세 개(기억 · 5시간 · 이번 주)와 남은 시간
  - 폴더 · 가지 · 세션 시간 · 질문 수 · 쓴 돈
  - 쓴 스킬·MCP 칩(노랑 쓰는 중 · 초록 쓴 것 · ×횟수)
  - 맨 아래에 지난 요청에 쓴 것, 오른쪽 끝에 오늘 합계(질문 수 · 쓴 돈)
- 고양이는 눈을 깜빡이고, 일할 때 걷고, 잘 끝나면 웃고, 기억이나 한도가 많이 차면 걱정합니다.
- 작업이 끝나면 띠 전체가 세션마다 정해진 짙은 색으로 칠해집니다 (작업 완료 알림).
- 기억(컨텍스트)이 차 갈수록 날씨가 맑음 → 구름 → 비 → 폭풍으로 바뀝니다.
- 데스크톱 앱에 Desktop Statusline 플러그인이 함께 켜져 있으면, 같은 내용이 영어로 한 번 더 나오지 않게 그 줄을 숨깁니다.
- 터미널에서는 클로드 캐릭터와 글자 세 줄로 나옵니다.

스킬·MCP 이름 목록은 만든 컴퓨터에 설치된 것을 기준으로 고정되어 있습니다. 목록에 없는 스킬·MCP는 띠에 나오지 않습니다.

## 설치

터미널의 Claude Code 입력창에서:

```
/plugin install tool-map --marketplace xldkfwl231-create/tool-map
```

셸에서:

```
claude plugin install tool-map --marketplace xldkfwl231-create/tool-map
```

Claude 데스크톱 앱에서: 입력창 옆 **+** → **Plugins** → **Add marketplace**에 `xldkfwl231-create/tool-map`을 넣고, **Add plugin**을 누릅니다.
